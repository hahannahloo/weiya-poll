1. 上傳文件

    📘 檢核規則

    分公司、總公司各一套規則。每次儲存都是新版本，舊版本可以隨時載入還原；每筆檢核紀錄都會記下當時用的版本。

    範例改版了？上傳新範例，讓 AI 產生規則草稿

    上傳新的送件範例（含紅字標註的 PDF 或照片都可以）。AI 會比對目前的規則，產生更新後的全文放進下方編輯區，並列出改了哪些地方。草稿不會自動生效，請核對後再按「儲存為新版本」。

    歷史版本

    🔑 註冊碼

    同仁註冊帳號時要輸入這組註冊碼，沒有註冊碼的人無法使用（避免外人亂用、花費 API 費用）。要停止開放註冊，把註冊碼清空後儲存即可。更換註冊碼不影響已註冊的帳號。

    🗂️ 資料保存期限

    超過天數的資料，系統每天凌晨 2 點會自動刪除。留空 = 不自動刪除。每次刪除都會記在使用紀錄裡。

    ・檔案到期：只刪照片、PDF 等原始檔案，檢核結果仍然看得到。
    ・結果到期：整筆紀錄（含檔案）都刪除。
    ・使用紀錄（誰、何時、做了什麼）不會被刪除。

    👥 帳號管理

    同仁可以用註冊碼自行註冊，也可以由管理者在這裡直接建立。要讓某人成為管理者，按「編輯」把權限改成管理者。內建帳號 admin 的密碼在 Cloudflare 的 ADMIN_PASSWORD 設定，不會列在這裡。

    📅 國定假日行事曆

    任用意見表的報到日期必須是每週或每月的第一個工作日，系統依這裡的行事曆計算。請上傳人事行政總處公告的行事曆（PDF、圖片、Excel、CSV 都可以），每年一次；同一年重新上傳會覆蓋舊的。

    📝 使用紀錄

    最近 200 筆。只記錄誰、什麼時候、檔名和結果，不保存檔案內容。
