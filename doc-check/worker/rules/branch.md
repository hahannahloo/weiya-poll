# 分公司業務任用送件 檢核標準

一份完整的送件包含「任用必備文件 1～7」。使用者可能上傳一個合併的 PDF、多個 PDF、手機翻拍照片、Word 或 Excel，順序可能打亂，請先判斷每一頁屬於哪一份文件。

## 文件 1：任用意見表（永豐金證券【新進人員任用意見表】，共 2 頁中的第 1 頁）
1-1 版本：右下角「版本日期」必須是 2026/06/23。不是最新版 → 不通過（請至永豐雲知識庫下載最新版，勿沿用舊存檔）。
1-2 填寫日期：右上「填寫日期」必須寫完整的年、月、日（民國或西元皆可），不可空白或仍是「民國年月日」字樣。
1-3 任用人員：必須填寫姓名。
1-4 任用單位：必須填寫「○○分公司/科別」，不可保留「○○」範本字。
1-5 工作性質：必須完全照標準填寫，只能是「金融跨售專員」、「儲備理財專員」、「營業員」其中之一（字要一模一樣）。未完全照此標準填 → 不予送件。
1-6 學歷、經歷：必須填寫，且與文件 3 履歷資料表一致（學校、最近任職公司）。意見表可以寫得較簡略，例如履歷是「○○大學五專部」、意見表寫「大學」或「五專」都可以接受。只有明顯是不同學校或不同公司（可能誤用上一位應徵者資料）才判不通過。
1-7 報到日期：必須寫完整的年、月、日（民國或西元皆可）。報到日必須是「每週第一個工作日」或「每月第一個工作日」，請對照訊息中提供的「可報到日期表」，不在表上 → 不通過，並建議最接近的可報到日期。若表上註明某年行事曆尚未上傳，該年度的日期判斷改列 warn。
1-8 評註：不可空白。
1-9 主試評語／試用期標準：「(必填) 試用期間 AP 項目須達月均 ○ 倍」必須填入具體倍數，不可保留「○」。其他試用條件可自行補充（例：開戶數○戶、須取得○○證照），若有寫也不可保留「○」。
1-10 主管指派 Mentor：員工編號、員工姓名、聯繫電話三欄都必須填寫，不可是「請務必填寫」字樣。
1-11 工作班別：分公司標準班別為「08:00-16:30」，勾選 → 通過。表單預設為總公司班別，最常見的錯誤是忘了改：勾的是 08:00-17:00 或其他班別 → 警告（可能是核准的例外，請確認；若是忘了修改請改為 08:00-16:30），並在 finding 寫出看到的班別。勾「其他班別」卻沒寫時間 → 不通過。
1-12 工作地點：必須填寫分公司實際名稱，不可保留「○○」，且與任用單位一致。
1-13 建議職等：必須填寫。
1-14 對外職稱：「依公司規定」或「請特殊考慮」必須擇一勾選；勾「請特殊考慮」需寫明職稱。
1-15 薪資總額：本薪必須填寫；伙食津貼為 3,000；薪資總額 = 本薪 + 伙食。若表上有寫總額，請驗算，對不上 → 不通過。金額需與應徵者相符，勿誤用上一個應徵者資料。
1-17 特別休假：「依公司規定」或「請特殊考慮 ___ 天/年」擇一勾選。勾特殊考慮時，必須寫「總天數」單一數字（例：10 天就寫 10 天），不可寫成「7+3」或只寫增加的「3」。超過 14 天必須附「現職假卡」供參，沒附 → 不通過。
1-18 頁碼：應為「第1頁/共2頁」。
1-19 名片（提醒）：如需印名片，須另填「預定報到同仁名片印製表」隨本表送出。此項只做提醒，不判不通過。
1-20 會簽欄（董事長、總經理…部門主管）：送件時可以空白，不檢核。

## 文件 2：新進員工面談紀錄表（共 2 頁中的第 2 頁）
2-1 版本：右下角「版本日期」必須是 2026/06/23。
2-2 姓名、部門（○○分公司/科別）、面談日期必須填寫，不可保留範本字。部門需與文件 1 任用單位一致。
2-3 工作性質：同 1-5，只能是三種標準名稱之一，且必須與文件 1 相同。
2-4 姓名、部門必須與文件 1 一致。
2-5「合適或不合適此應徵職務之原因」不可空白。
2-6「綜合評語」不可空白。
2-7 面談表現狀況（請務必記得勾選）：學經歷、言行舉止、情緒反應、自信心、專業知識、發展潛力，六項「每一項都必須剛好勾選一個」。漏勾或重複勾 → 不通過，並指出是哪一項。
2-8 GAI/AI 能力：使用頻率、應用能力、作品或專案成果三項必須各勾一個。「使用工具」建議填寫（空白列為警告）。「證照/認證」可不勾。
2-9 面試主管建議：「任用／安排進階面談／待考慮／不合適」必須勾選一個。勾的不是「任用」→ 警告（送任用件卻非建議任用）。
2-10 最快報到日：必須寫完整的年、月、日（民國或西元皆可，即使欄位印「西元」也可寫民國年）。不用檢查是否為週首或月初。
2-11 部門主管簽名：必簽。空白 → 不通過。
2-12 面試主管簽名：必須簽名。空白 → 不通過。
2-13 頁碼：應為「第2頁/共2頁」。

## 文件 3：履歷資料表
有兩種版本都可以：(a) 招募系統列印的「履歷資料表」（約 3 頁，右下有 1/3、2/3、3/3）；(b) 紙本「應徵人員履歷資料表」（手寫，2 頁：基本資料／教育背景／工作經歷，語言能力／證照／應徵資訊）。兩種版本適用同一套規則。
3-1 必須是「履歷資料表」，不可用「人事資料表」代替 → 用錯 → 不通過。
3-2 基本資料：中文姓名、身分證字號或護照號碼、國籍、生日、行動電話、Email、通訊地址必須有內容。姓名必須與文件 1、2 一致。
3-3 兵役狀況：男性需填寫（例：役畢＋日期）。
3-4 教育背景－校名：必須寫畢業證書上的校名；學校後來改制，也不可直接寫現行名稱。若與文件 4 畢業證書校名不同 → 不通過。
3-5 教育背景－科系：專科以上學歷的科系「不可能是普通」，一定有科系名稱。最高學歷（專科以上）科系寫「普通」→ 不通過。
3-6 修業期間（起訖都要填，且起在前、訖在後；一般 9 月入學、6 月畢業，月份明顯顛倒 → 警告）：排除延畢、重考等因素，正常就學期間為：碩士 2 年；大學 4 年；二技 2 年；五專 5 年；二專 2 年；高中 3 年；夜間部一般多 1 年。修業期間比正常年數長或短，必須註明原因（例：大學五年，因為延畢）。未註明 → 不通過。
3-7 最高學歷與次高學歷：年度應該接續。有中斷要確認是延畢或重考並手寫註明；若是填寫錯誤，必須上招募系統修正。
3-8 已畢業：勾已畢業者必須已取得畢業證書（並附文件 4）。學分未修完、檢定考未通過等尚未取得畢業證書者，不可勾已畢業，應填「就學中」。
3-9 工作經歷：必須從役畢／畢業開始填寫，依時間逐段列出。各段之間中斷超過半年，必須填寫「待業」或其他原因說明。未說明 → 不通過。
3-10 年資：每段年資應與服務期間相符（容許約 0.1 年誤差），在職中的以列印日計算。明顯對不上 → 警告。
3-11 薪資：每段需填月薪與年薪（月薪＝本薪含伙食；年薪＝前年度總所得）。空白 → 警告（必要時會請應徵者提供佐證）。
3-12 離職原因：每段已離職的工作都要填寫（在職中的可免填）。空白 → 不通過。
3-12a 職務內容：每段工作經歷都必須填寫職務內容。空白 → 不通過。
3-13 手寫補經歷：2027 年起不接受手寫補經歷，必須上招募系統修改。今天是 2027 年或之後且看到手寫補充的經歷 → 不通過；2027 年以前 → 警告提醒。
3-14 證照：金融相關證照、其他證照、AI 技能／檢定證照欄位應有內容（沒有就寫「無」）。
3-15 照會人（請您提供 1～2 位過去工作直屬主管或學校教授供照會）：
   - 有工作經歷：必須填曾任職公司的「直屬主管」。
   - 只有一份工作經歷且在職中：可填曾就讀學校的教授。
   - 無工作經歷：填曾就讀學校的教授。
   - 照會人的服務單位必須是工作經歷表上「有出現」的公司。填了沒有任職過的公司 → 不通過。
   - 主管已離開該公司，服務單位仍要寫當時共事的那間公司，以利核對。
3-16 可報到日期、期望待遇：必須填寫。
3-17 應徵資訊的是非題（是否曾面試/任職本公司、親友、解除職務、違紀處分、票據信用/刑事紀錄、法院強制扣押薪資等）都必須有答案。任何一題答「是」（推介至集團其他職位那題除外）→ 警告，請主管確認。
3-18 填表人簽名：必須由應徵者親自簽名並填日期。2027 年起送任用簽核時履歷表未簽名不予送件：今天是 2027 年或之後未簽 → 不通過；2027 年以前未簽 → 警告（報到當天須補簽，會延遲報到程序）。

## 文件 4：最高學歷（已畢業）之畢業證書影本
4-1 若文件 3 最高學歷為已畢業，必須附畢業證書影本。沒附 → 不通過。
4-2 證書上的姓名、校名、科系必須與文件 3 一致。

## 文件 5：任用效益評估
5-1 標題前需填應徵者姓名，且與其他文件一致。
5-2「一、試用期間預估」不可空白。
5-3「二、試用期過後預估效益」不可空白。
5-4「主管：」必須簽名或填寫。

## 文件 6：徵信（證交所聯合徵信資料）
6-1 必須附上。姓名需與其他文件一致。
6-2 查詢資料日應在送件前 1 個月內（以今天日期判斷），過舊 → 警告。
6-3 冒名開戶、訴訟判決、交付偽變造證券、連續開戶、被冒開戶、違約、持偽變造證開戶、被解除職務紀錄：應全部為 N。任一項為 Y → 不通過（需主管說明）。
6-4 融資、融券、借貸款項等餘額不為 0 → 只列為提醒，不判不通過。

## 文件 7：一類票查（第一類票據信用資料查覆單）
7-1 必須附上。戶名需與其他文件一致。
7-2 查詢日應在送件前 1 個月內，過舊 → 警告。
7-3 退票紀錄（存款不足、發票人簽章不符、擅自指定金融業者為本票之擔當付款人、本票提示期限經過前撤銷付款委託）的張數、金額應全部為 0；否則 → 不通過。
7-4 拒絕往來資訊應為「無拒絕往來紀錄」；有拒絕往來 → 不通過。
7-5 應有票據交換所（查詢單位）的戳章與日期。看不到戳章 → 警告。

## 日期格式（所有文件）
D-1 所有日期民國、西元皆可（不論欄位上印哪一種），但必須寫完整的年、月、日。缺年、缺月或缺日 → 不通過。

## 跨文件一致性
X-1 應徵者姓名在所有文件中必須一致。
X-2 工作性質在文件 1、2 必須一致。
X-3 文件 1 的報到日期，不應早於文件 2 的「最快報到日」及文件 3 的「可報到日期」。早於 → 警告。
X-4 文件 1 的學歷、經歷必須與文件 3 一致（誤用上一位應徵者資料是最常見的錯誤）。
X-5 文件 1～7 是否齊全。缺少任何一份 → 不通過（文件 4 僅在已畢業時需要）。
