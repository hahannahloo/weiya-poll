# 任用送件檢核：使用說明

上傳新進人員的任用送件（文件 1～7），AI 會依「分公司業務任用送件範例」逐條檢查，列出不通過的地方、位置和修正方式，可以一鍵複製說明或下載 PDF 報告。

- 網頁：`https://你的網址/doc-check/`
- 支援：PDF、照片（JPG／PNG／HEIC，手機拍照也可以）、Word（.docx）、Excel（.xlsx／.csv）
- 檢核標準：`worker/rules.md`（分公司、總公司皆可，上傳時可選送件單位）

## 架構
| 部分 | 位置 | 說明 |
|---|---|---|
| 網頁 | `doc-check/index.html` | 跟投票網站一起放在 Vercel。照片會先在手機上壓縮，Word／Excel 會先轉成文字 |
| 檢核伺服器 | `doc-check/worker/` | Cloudflare Worker，負責保管 API 金鑰、把檔案交給 Claude 檢核 |

檔案只在檢核當下傳給 Claude，伺服器不會儲存。Anthropic API 預設不會拿你的資料訓練模型。不過文件含有個資，請先確認公司是否允許使用外部 AI 服務。

## 第一次設定（約 10 分鐘）

### 1. 申請 Claude API 金鑰
1. 到 https://console.anthropic.com 註冊並登入。
2. **Billing** 儲值，最少 5 美元。
3. **API Keys** → **Create Key**，複製產生的金鑰（`sk-ant-` 開頭）。金鑰只會顯示一次。

### 2. 部署檢核伺服器（Cloudflare）
1. 登入 https://dash.cloudflare.com → **Compute (Workers)** → **Workers & Pages** → **Create**。
2. 選 **Import a repository**，選 `weiya-poll`。
3. 設定頁：
   - Project name：`doc-check-api`
   - **Advanced settings** → Path（根目錄）填 `/doc-check/worker`
   - Deploy command：`npx wrangler deploy`
4. 按 **Deploy**，完成後會得到網址，例如 `https://doc-check-api.你的帳號.workers.dev`。
5. 進入這個 Worker → **Settings** → **Variables and Secrets** → **Add**，新增兩個 **Secret**：
   - `ANTHROPIC_API_KEY`：第 1 步的金鑰
   - `ADMIN_PASSWORD`：內建管理者帳號 **admin** 的密碼，自己訂一組夠長的密碼（至少 12 個字元）

用瀏覽器打開伺服器網址，看到「任用送件檢核伺服器運作中 ✅」就成功了。

### 3. 把伺服器網址填進網頁
打開 `doc-check/index.html`，找到 `const CONFIG = {`，把網址填進 `apiUrl`：
```js
apiUrl: "https://doc-check-api.你的帳號.workers.dev",
```
推上 GitHub 後 Vercel 會自動更新。在 `apiUrl` 填入之前，網頁會是**示範模式**，只顯示範例結果。

## 帳號、權限與紀錄
不串公司的帳號系統。同仁用「註冊碼」自行註冊，管理者不用一個一個建帳號。

| 權限 | 可以做的事 |
|---|---|
| 使用者 | 上傳檢核、查看**自己**的檢核紀錄（上傳的檔案和結果）、改自己的密碼 |
| 管理者 | 查看**所有人**的檢核紀錄、刪除紀錄、管理帳號、設定註冊碼、上傳行事曆、看使用紀錄 |

**第一次設定：**
1. 用帳號 `admin`、密碼 `ADMIN_PASSWORD` 登入。
2. 點上方「管理」，在「🔑 註冊碼」設一組註冊碼並儲存。
3. 把網址和註冊碼告訴同仁。同仁在登入頁按「註冊新帳號」，填帳號（建議用員工編號）、姓名、密碼和註冊碼就能使用。
4. 建議替自己註冊一個帳號，再到「帳號管理」按「編輯」，把權限改成管理者，平常用這個帳號；admin 留著備用。

**歷史軌跡：**
- 每次檢核都會保存**上傳的檔案和檢核結果**，在上方「我的紀錄／全部紀錄」可以隨時回來看、重新開啟檔案。
- 使用者不能刪除紀錄，只有管理者可以；每次刪除都會記在「使用紀錄」，包括誰刪的、刪了哪一筆。
- 「管理」頁的「📝 使用紀錄」會記錄所有動作：註冊、檢核、帳號異動、設定註冊碼、上傳行事曆、刪除紀錄。

**日常管理：**
- **有人離職**：在帳號管理按「編輯」，取消勾選「啟用」，對方會立刻被登出、無法再登入。他的檢核紀錄會保留。
- **忘記密碼**：按「編輯」，在「重設密碼」填一組新密碼，再告訴對方。
- **註冊碼外流**：直接換一組新的。已經註冊的帳號不受影響。不想再開放註冊，就把註冊碼清空。
- 密碼加密後才儲存，連管理者也看不到別人的密碼。

**資料保存提醒：** 檢核紀錄裡有應徵者的個資（身分證字號、電話等），會保存在 Cloudflare 上，直到管理者刪除為止。請依公司的個資保存規定，定期刪除不需要的紀錄。Cloudflare 免費方案大約可以存 5GB（大約幾百到上千件送件），升級 Workers Paid（每月 5 美元）可以存更多，運算時間也比較充裕。**正式使用建議升級 Workers Paid**。

## 怎麼用
1. 打開網頁，上傳整份送件。合併成一個 PDF、分成多個檔案、手機逐頁拍照都可以，順序不拘。
2. 有特殊狀況可以寫在「補充說明」（例如：應徵者無工作經歷、特休超過 14 天已另附假卡）。
3. 用自己的帳號登入，7 天內不用重新登入。
4. 按「開始檢核」，約 1～3 分鐘。
5. 看結果：
   - ❌ 不通過：必須修正
   - ⚠️ 需確認：AI 看不清楚或需要人工判斷
   - 「📋 複製不通過說明」可以直接貼到 LINE 或 Email 給承辦人
   - 「🖨️ 下載報告」可以存成 PDF

## 修改檢核標準（用手機就能改）
所有規則都在 **`doc-check/worker/rules.md`**，是一般的中文文字檔。

**手機上修改：**
1. 用瀏覽器打開 `github.com/hahannahloo/weiya-poll`，進入 `doc-check/worker/rules.md`。
2. 點右上角的筆（✏️ Edit），直接改文字。
3. 按 **Commit changes** 存檔，Cloudflare 約 1 分鐘後自動更新，之後的檢核就用新規則。

**常見的修改：**
- 表單改版：改 1-1、2-1 的版本日期（目前是 `2026/06/23`）
- 新增規則：在對應的文件段落加一行，寫清楚「什麼情況算不通過／警告」
- 取消規則：整行刪掉
- 國定假日：不用改這個檔案，請在網頁最下方「📅 國定假日行事曆」上傳人事行政總處的行事曆（見下一節）

**改壞了怎麼辦：** GitHub 上每次修改都有紀錄。在檔案頁面點 **History** 可以看到誰、什麼時候、改了什麼，也可以找回舊版本複製貼回。

**AI 判錯怎麼辦：** 把那條規則寫得更具體，例如加上「○○情況可以接受」或舉例。

## 上傳國定假日行事曆（每年一次）
任用意見表的報到日期必須是「每週第一個工作日」或「每月第一個工作日」，系統依行事曆計算哪些日子可以報到。
1. 到行政院人事行政總處網站下載「政府行政機關辦公日曆表」。PDF、圖片、Excel、CSV 都可以，開放資料的 CSV 最準確。
2. 打開檢核網頁，用管理者帳號登入，點上方「管理」，找到「📅 國定假日行事曆」，按「上傳行事曆」。只有管理者看得到這個功能。
3. 約 1 分鐘後會列出讀到的放假日和補班日，**請核對一次**。有錯就重新上傳，同一年會覆蓋舊的。

跨年時請上傳隔年的行事曆。還沒上傳的年份，報到日期只會排除週末，相關檢核會列為「需確認」。

## 費用
每份送件約新台幣 10～20 元，依頁數和照片多寡而定。實際用量可到 console.anthropic.com 的 **Usage** 查看，建議在 **Limits** 設定每月上限。

## 常見問題
- **忘記密碼**：一般帳號請管理者在「管理」頁重設；admin 的密碼到 Cloudflare 修改 `ADMIN_PASSWORD`。
- **密碼輸錯 5 次**：帳號會鎖定 15 分鐘，時間到就能再試。
- **出現「API 金鑰無效」**：檢查 Cloudflare 的 `ANTHROPIC_API_KEY` 是否貼錯，或 Anthropic 帳戶是否沒有餘額。
- **出現「Exceeded CPU」或檢核一直失敗**：Cloudflare 免費方案每次運算時間很短，檔案很大時可能不夠。可以分批上傳，或升級 Workers Paid（每月 5 美元）。
- **舊版 .doc 檔**：請先另存成 .docx 或 PDF。
- **AI 判斷錯誤**：AI 檢核結果僅供參考。如果某條規則常常判錯，可以把 `rules.md` 裡那條寫得更具體。
